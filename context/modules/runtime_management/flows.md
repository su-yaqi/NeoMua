# Runtime Management Flows

## 节点注册与恢复

1. admin 创建 15 分钟一次性令牌。
2. 节点生成 Ed25519 密钥，只上传公钥；平台原子消费令牌并签发 90 天设备凭证。
3. 节点建立出站 WSS，每 20 秒心跳；超过 60 秒显示离线，但配对和凭证保留。
4. 关机一天后节点仍使用原身份重连，提交 spool、配置版本和中断任务对账。
5. 到期前 30 天轮换；节点原子保存新凭证、重连确认后平台吊销旧凭证。

## 任务执行

任务创建时冻结模型路由、模型、工具、目录 allowlist、超时和执行器版本。节点先把 `(task_id, revision)` 写入 SQLite 才确认调度；所有事件先写 spool 再发送。平台按序幂等入库并返回连续 ACK。租约过期或进程重启只标记 interrupted，必须由用户显式 retry。

## 内容分发

admin 上传 ZIP 后平台逐文件计算哈希、拒绝路径逃逸/符号链接并签署不可变清单。发布再签署 namespace/node/deployment scope。节点下载后重新验证双签名、ZIP 哈希、每个文件哈希/大小和逻辑目标，在本地 allowlist 根目录同文件系统 staging，最后原子切换 current；不存在执行钩子。
