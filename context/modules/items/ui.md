## 页面详情

### 条目管理页
- **路由**：`/items`
- **说明**：当前登录用户管理个人条目。
- **权限**：登录用户

**页面结构**
标题区 + 新增按钮 + 空状态 / 表格区域。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 查看列表 | 页面加载 | 拉取前 100 条条目 |
| 新增条目 | 点击 `AddItem` | 弹窗填写标题、描述后保存 |
| 编辑条目 | 行操作菜单 | 更新标题、描述 |
| 删除条目 | 行操作菜单 | 二次确认后删除 |

**字段说明**
| 字段 | 类型 | 说明 | 校验规则 |
|------|------|------|---------|
| title | 输入框 | 条目标题 | 必填，长度 1-255 |
| description | 文本框 | 条目描述 | 可选，长度 <=255 |
