# items 业务流程

## 核心流程

### 条目列表读取

**步骤**
1. 用户进入 `/items`。
2. 前端调用 `/items?skip=0&limit=100`。
3. 后端根据 `current_user.is_superuser` 判断读取范围。
4. 返回列表与总数，前端用通用 `DataTable` 渲染。

### 条目创建 / 编辑 / 删除

**步骤**
1. 用户通过弹窗填写标题和描述。
2. 创建时后端将 `owner_id` 写成当前用户 ID。
3. 编辑和删除前，后端检查目标条目是否存在。
4. 若非超级管理员且非 owner，则返回 403。

## 业务规则

- `title` 必填，`description` 可选。
- 普通用户只能管理自己的条目。
- 超级管理员可读取和操作全部条目。

## 数据读写

| 操作 | 表 | 说明 |
|------|-----|------|
| 读 | item | 列表查询、详情查询 |
| 写 | item | 创建、更新、删除条目 |
| 读 | user | 通过 `current_user` 做 owner 权限判断 |

## 异常场景处理
| 场景 | 处理方式 |
|------|---------|
| 条目不存在 | 返回 404 |
| 无权限操作他人条目 | 返回 403 |
