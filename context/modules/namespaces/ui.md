# namespaces 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 空间管理页 | /system/namespaces | 平台空间列表与 CRUD |
| 空间成员管理页 | /system/namespaces/:namespaceId/members | 当前空间成员列表与成员管理 |
| 顶部空间选择器 | 全局布局 | 切换当前上下文空间 |

## 页面详情

### 顶部空间选择器
- **路由**：全局布局 `/_layout`
- **说明**：显示当前用户可见空间并允许切换。
- **权限**：登录用户

**页面结构**
顶部栏右侧 `Select` 组件。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 首次选中空间 | 页面加载 | 若本地无缓存则自动选中第一个空间 |
| 切换空间 | 下拉选择 | 写入 `selected_namespace_id` 并刷新页面 |

### 空间管理页
- **路由**：`/system/namespaces`
- **说明**：平台空间列表页，支持创建空间并进入指定空间的成员管理页。
- **权限**：`superuser`

**页面结构**
标题区 + “新增空间”按钮 + 数据表格。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 新增空间 | 弹窗表单 | 录入空间名称，前端自动生成 `code` |
| 进入成员管理 | 行内按钮 | 跳转到当前空间的成员管理页 |
| 编辑空间 | 行菜单 | 修改名称与启用状态 |
| 删除空间 | 行菜单 | 二次确认后删除 |

### 空间成员管理页
- **路由**：`/system/namespaces/:namespaceId/members`
- **说明**：当前已选空间的成员管理页面。
- **权限**：`superuser` 或该空间的 `admin`

**页面结构**
标题区 + “新增成员”按钮 + 成员表格 + 行操作菜单。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 查看成员 | 页面加载 | 读取当前空间成员列表，展示姓名、邮箱、空间角色、全局角色、启用状态 |
| 新增成员 | 弹窗表单 | 邮箱已存在则复用用户后关联空间；不存在则先创建再关联 |
| 编辑成员角色 | 行菜单 | 调整当前空间内的角色 |
| 移除成员 | 行菜单 | 仅移除空间关联，不删除平台用户主体 |

## 补充说明

- 左侧导航已新增独立的“空间成员管理”入口，目标始终指向当前 `selected_namespace_id`。
- 空间成员管理页依赖父级 `/system/namespaces` 路由渲染 `Outlet`；此前缺失该出口会导致子页无法显示。
