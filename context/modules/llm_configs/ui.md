# llm_configs 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 大模型接入配置页 | /system/llm-providers | 当前空间的大模型供应商配置列表与维护入口 |
| 配置弹窗 | /system/llm-providers | 新增/编辑接入配置、更新密钥、连接校验、模型同步 |

## 页面详情

### 大模型接入配置页
- **路由**：`/system/llm-providers`
- **说明**：按当前已选空间展示接入配置列表，支持新建配置和编辑既有配置。
- **权限**：当前实现中已登录且已选空间用户可见导航，实际接口权限由后端限制为 `superuser` 或空间 `admin`

**页面结构**
标题区 + “新增配置”按钮 + 数据表格。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 读取供应商目录 | 页面加载 | 获取供应商清单、密钥字段定义和默认地址 |
| 读取配置列表 | 页面加载 | 展示配置名称、供应商、启用状态、校验状态、模型数量 |
| 新增配置 | 顶部按钮 | 打开弹窗录入供应商、地址、密钥和模型 |
| 编辑配置 | 行内按钮 | 打开同一弹窗修改当前配置 |

### 配置弹窗
- **路由**：`/system/llm-providers`
- **说明**：统一承担新增、编辑、连接校验、模型同步和手工模型维护。
- **权限**：同上

**页面结构**
基础配置区域 + 动态密钥字段区域 + 扩展参数区域 + 模型管理区域 + 页脚操作区。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 选择供应商 | 下拉框 | 根据供应商目录自动切换默认地址、密钥字段和扩展字段 |
| 安全展示密钥 | 编辑已有配置 | 密码输入框仅展示掩码提示，留空表示沿用旧密钥 |
| 校验连接 | 按钮 | 对已保存配置执行在线校验并提示结果 |
| 同步模型 | 按钮 | 拉取供应商模型并刷新模型列表 |
| 补录手工模型 | 表单 + 按钮 | 允许手工添加模型 ID 和展示名 |
| 启用/禁用模型 | 模型行复选框 | 维护当前配置可用模型集合 |

## 补充说明

- 若顶部尚未选择空间，页面直接提示先选择空间。
- 供应商切换只允许在新建时进行；编辑态中供应商只读。
- 本期未提供默认模型配置入口，该能力后续再独立设计。
