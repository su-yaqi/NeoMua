# auth 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 登录页 | /login | 账号登录 |
| 注册页 | /signup | 公开注册 |
| 找回密码页 | /recover-password | 发送重置邮件 |
| 重置密码页 | /reset-password | 设置新密码 |

## 页面详情

### 登录页
- **路由**：`/login`
- **说明**：邮箱密码登录。
- **权限**：未登录用户

**页面结构**
认证布局 + 登录表单 + 跳转注册链接与找回密码入口。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 登录 | 提交表单 | 调用登录接口，成功后写入 Token 并跳转首页 |
| 跳转找回密码 | 点击链接 | 前往 `/recover-password` |
| 跳转注册 | 点击链接 | 前往 `/signup` |

### 注册页
- **路由**：`/signup`
- **说明**：公开创建普通账号。
- **权限**：未登录用户

**字段说明**
| 字段 | 类型 | 说明 | 校验规则 |
|------|------|------|---------|
| full_name | 输入框 | 姓名 | 必填 |
| email | 输入框 | 邮箱 | 必填，合法邮箱 |
| password | 密码框 | 密码 | 必填，最少 8 位 |
| confirm_password | 密码框 | 确认密码 | 必填，需与密码一致 |

### 找回密码页
- **路由**：`/recover-password`
- **说明**：提交邮箱发起密码找回。
- **权限**：未登录用户

### 重置密码页
- **路由**：`/reset-password?token=...`
- **说明**：携带 token 设置新密码；无 token 时直接重定向登录页。
- **权限**：未登录用户
