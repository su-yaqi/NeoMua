# users 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 用户管理页 | /admin | 超级管理员管理平台用户 |
| 个人设置页 | /settings | 当前用户修改资料、密码和注销 |

## 页面详情

### 用户管理页
- **路由**：`/admin`
- **说明**：展示用户列表并支持新增、编辑、删除。
- **权限**：超级管理员

**页面结构**
标题区 + “新增用户”按钮 + 用户表格 + 行操作菜单。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 新增用户 | 点击 `AddUser` 弹窗 | 填写邮箱、姓名、密码、状态、超级管理员标记，并可设置初始空间关联 |
| 编辑用户 | 行操作菜单 | 修改邮箱、姓名、启用状态、超级管理员标记 |
| 删除用户 | 行操作菜单 | 二次确认后删除 |

**当前展示约束**
- 平台用户表格不再展示“空间关联 / 空间角色摘要”列。
- 平台用户编辑弹窗不再允许修改空间关联；空间成员关系统一在空间成员管理页维护。
- 新增用户弹窗仍支持设置初始空间关联，作为创建阶段的一次性分配入口。

### 个人设置页
- **路由**：`/settings`
- **说明**：当前用户的资料维护中心。
- **权限**：登录用户

**页面结构**
标题区 + Tabs（My profile / Password / Danger zone）。

**调用接口**
| 时机 | 接口 | 说明 |
|------|------|------|
| 页面加载 | GET `/users/me` | 获取当前用户资料 |
| 保存资料 | PATCH `/users/me` | 更新邮箱与姓名 |
| 修改密码 | PATCH `/users/me/password` | 更新密码 |
| 删除账号 | DELETE `/users/me` | 注销当前用户 |

## 补充说明

- 平台用户更新接口的重复邮箱场景当前返回 `409`，避免出现服务端 `500`。
- 平台用户的空间角色仍会在 API 返回体中携带，但前端平台治理页不再把它作为主列表字段展示。
