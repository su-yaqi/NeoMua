# v0.3 变更记录

## 基本信息
- 完成时间：2026-06-11
- 对应 PRD：`context/prds/v0.3/`

## 实现内容

### llm_configs
- 后端新增 `llm_provider_config`、`llm_provider_model` 两张表及配套 Alembic 迁移。
- 新增 `/api/v1/llm/*` 路由，支持供应商目录、空间级接入配置 CRUD、连接校验、模型同步。
- 后端内置完整供应商预置目录，并复刻参考项目已支持的供应商集合。
- 接入配置密钥以加密密文存储，对外仅返回掩码；编辑时支持留空沿用旧密钥。
- 已接入连接校验和模型自动拉取能力；不支持自动发现的供应商允许仅维护手工模型。

### namespaces / auth
- `llm` 接口统一复用 `require_namespace_admin`，确保所有配置都严格绑定当前空间。
- `tenantApi` 继续通过 `X-Namespace-Id` 传递当前空间上下文，无需引入新的上下文机制。

### frontend
- 新增 `/system/llm-providers` 页面及侧边栏入口。
- 新增统一配置弹窗，支持供应商切换、动态字段渲染、密钥安全展示、连接校验、模型同步、手工模型维护。
- 列表页可查看配置启用状态、连接校验状态和模型数量等信息。

### testing
- 新增 `backend/tests/api/routes/test_llm_provider_configs.py`，覆盖配置创建、更新、校验、模型同步和权限场景。
- 原有 `backend/tests/conftest.py` 已补齐新表初始化与清理逻辑。
- 前端经 `npm run build` 验证通过。

## 遗留问题

- 左侧“大模型接入配置”导航当前按“已登录且已选择空间”展示，前端未进一步按角色隐藏，最终仍以后端权限控制为准。
- `oauth_external`、`external_process` 等供应商类型本期仅完成配置结构与展示，不包含完整外部授权流程。
