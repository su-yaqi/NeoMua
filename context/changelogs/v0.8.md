## 实现内容

- Skill 从仅上传 ZIP 的受管制品升级为空间级内容资产。`/system/skills` 保留外层列表，详情提供左侧文件目录树、右侧文本编辑器与 Markdown 预览。
- 新增 Skill 单一草稿、文件存储、CAS revision 和校验证据；支持文本/二进制文件、路径规范化、安全 ZIP 导入、文件创建/更新/移动/删除。
- 草稿必须在当前 revision 完整校验后才能发布；发布生成内容寻址、Manifest 摘要和平台签名的不可变 Bundle，并原子推进显式 `current_version_id`。历史版本只读，current 切换/回滚保留幂等审计。
- Agent 草稿、Plugin contribution 和 Agent Release 改为只绑定 Skill identity，不再配置或冻结 Skill Version；Plugin Version、MCP Revision 和 Agent Release 自身仍保持精确不可变。
- 新增 `runtime_skill_state` 与 `runtime_skill_sync_attempt`，用 desired/applied、generation 和 attempt 记录每个 Runtime 的后台同步状态。平台 Worker 轮询同步；节点通过 WSS 通知与周期 reconcile 同步。
- Skill Bundle 按摘要缓存、验签和安全校验，采用 verified/commit 两阶段原子切换；重复摘要不重复解包。失败时保留上一 applied，首次无可用版本时明确阻断依赖它的激活或任务。
- 任务使用与同步彻底解耦：任务只为本地 applied 内容创建只读绑定，不查询控制面、不下载、不解包、不解析；每次任务通过 `agent_task_skill_usage` 记录实际版本、摘要和 Runtime generation。同一 Session 的后续任务可独立使用新同步版本。
- Skill 列表、详情、Runtime 平台卡片、节点详情与任务详情增加 current、desired/applied、同步状态、显式 retry 和任务使用证据展示。
- 新增 Alembic 迁移 `e8a1c4b7d902`，同时完成旧精确 Skill 绑定向 identity binding 的兼容迁移。
